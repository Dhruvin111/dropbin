Access from Any PC on Your Network

Anyone on your local Wi-Fi or LAN can access and collaboratively edit any bin by writing the server IP followed by /dropbin/ and the pad name:

http://192.168.6.201:8080/dropbin/{your-name}

Example: http://192.168.6.201:8080/dropbin/abc

✍️ Always in Edit Mode

Instant live typing. No extra buttons needed to edit. Tabs and line numbers are built right in.

📎 File Sharing (up to 10MB)

Seamlessly drag-and-drop or upload Images, PDFs, and Word documents (.doc, .docx). Preview or download immediately.

⏱️ 5-Minute Inactivity Expiry

Text and files are safely kept and auto-expire 5 minutes after inactivity. Any typing or file upload resets the 5-minute timer.

🔄 Multi-PC Real-Time Sync

Instant peer updates via Server-Sent Events (SSE). Text edits and new file uploads appear live on all connected screens.
